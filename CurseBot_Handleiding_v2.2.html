De Besturingsknoppen (Dashboard)

DIAGNOSTIEK

Foutafhandeling & Status

STATUSCODE / SYMPTOOMOORZAAK & INTERVENTIE
[ERROR] 'int' object...Vangt onverwachte CurseForge API response datatypes op. De bot herstelt hier automatisch van bij de volgende intervalcheck.
Zoeken geeft 0 resultatenControleer je netwerkverbinding en verifieer of je API Key niet verlopen is in het instellingenscherm.
[CF] 403 — X-Cache: Error from cloudfrontTijdelijke Cloudfront WAF IP-blokkade. NIET een API key probleem. Wacht 1–24 uur en herstart de bot daarna. Niet herhaaldelijk herstarten — dat verlengt de blokkade.
Bot stopt na X uur vanzelfControleer of de monitor_loop een @loop.error handler heeft (v2.1.0+). Zonder deze handler stopt de loop definitief bij de eerste onverwachte API fout.
Twee vensters openen bij startZorg dat start_cursebot.bat alleen python launch.py aanroept. launch.py v1.2.0 start bot én UI in één proces.
