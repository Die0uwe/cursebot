CurseBot
Slayer Alliance Edition — Configuratie
1
Discord Bot Token
Hoe krijg je dit?
  1. Ga naar discord.com/developers/applications
  2. Klik New Application → geef het een naam (bijv. CurseBot)
  3. Links klik op Bot
  4. Klik Reset Token → kopieer de lange code
  5. Scroll naar beneden: zet Message Content Intent aan
Begint meestal met MT... of OD...
2
Discord Channel ID
Hoe krijg je dit?
  1. Open Discord → Instellingen (tandwieltje links onder)
  2. Ga naar Geavanceerd → zet Ontwikkelaarsmodus aan
  3. Ga terug naar je server
  4. Rechtermuisklik op het channel waar CurseBot meldingen moet sturen
  5. Klik Kanaal-ID kopiëren
Een lang getal, bijv. 1234567890123456789
3
CurseForge API Key
Hoe krijg je dit?
  1. Ga naar console.curseforge.com
  2. Log in met je CurseForge account
  3. Klik op API Keys in het menu
  4. Klik Generate API Key
  5. Kopieer de key (trek een eventuele oude in!)
Begint vaak met $2a$10$...
4
Opslaan en klaar

Controleer je instellingen hieronder. Klik daarna op "Download .env" — sla het bestand op als .env in de cursebot map.

Discord Token: niet ingevuld
Channel ID: niet ingevuld
CurseForge Key: niet ingevuld

1
Open CMD (zwart venster)Windows + R → typ cmd → Enter
2
Navigeer naar de mapcd C:\CurseBot\cursebot

Installeer (eenmalig)python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Start de botDubbelklik op start_cursebot.bat
