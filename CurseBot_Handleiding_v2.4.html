06 / BOT INSTALLATIE

CurseBot toevoegen aan je server

CurseBot is gratis en open-source. Voeg hem toe aan elke Discord server waar jij administrator bent.

⚡ CurseBot — Slayer Alliance Edition
Vereiste rechten: berichten sturen · embeds · bestanden · geschiedenis lezen · slash commands
➕ Toevoegen
1
Klik op de knop hierboven
Discord opent een autorisatiepagina — log in als je dat nog niet bent.
2
Selecteer je server
Kies de server uit het dropdown menu — je hebt Administrator nodig.
3
Autoriseer de rechten
Controleer de gevraagde rechten en klik op Autoriseren.
4
Setup wizard
CurseBot stuurt automatisch een setup bericht. Gebruik /setup als dat niet gebeurt.
5
Kanaal instellen
Gebruik /setchannel om een kanaal te koppelen aan release notificaties. Je bent klaar!

Of gebruik in Discord: /invite — genereert een verse invite link voor andere servers.

07 / DIAGNOSTIEK

Foutafhandeling

403 + X-Cache: cloudfront
Tijdelijke Cloudfront WAF blokkade — geen auth-fout. Wacht 1–24 uur. Niet herstarten.
403 zonder X-Cache
API key ongeldig of verlopen. Controleer CURSEFORGE_API_KEY in Instellingen.
0 projecten na start
CF_AUTHOR_SLUG controleren — moet een naam zijn (bijv. dieouwe), geen getal.
Bot stopt na X uur
v2.1.0+ heeft de monitor_loop.error handler. Update naar de nieuwste versie.
Geen notificaties
Gebruik /setchannel om een kanaal te koppelen. Controleer rechten via /permissions.
Addon images niet zichtbaar
v2.0.0+ laadt images asynchroon. Update via start_cursebot.bat → updater pakt dit op.
