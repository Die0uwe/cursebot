Wat is er nieuw

Innovaties v2.3 → v3.0

Alles wat er de afgelopen sessies is gebouwd, gefixed en geïnnoveerd — per onderdeel.

🔍
Volledige Update Detectie
De monitor cog is volledig herbouwd. CurseBot detecteert nu updates voor ALLE addons — eigen addons via auteur-slug én elke addon op de watchlist van alle guilds. Vorige versie miste watchlist-addons van andere auteurs.
curseforge.py v3.0.0
📋
Release History Logging
Elke verstuurde Discord embed wordt nu opgeslagen in een release_history tabel in SQLite. Basis voor het geplande /history command — nooit meer de vraag "wanneer heeft de bot dat gestuurd?"
cache.py DB v4
🛡️
WAF Backoff Systeem
Cloudfront 403-blokkades worden automatisch herkend. De bot wacht 1 minuut, dan 5 minuten, dan 1 uur — zonder te crashen of in een loop te gaan. Bij de volgende succesvolle check reset hij automatisch.
curseforge.py v3.0.0
🔧
Runtime Package Fixer
De Pillow herstart-loop is voorgoed opgelost. launch.py checkt nu bij elke start — of het via .bat, .venv of .exe is — alle vereiste packages en installeert wat mist via pip, stil en automatisch.
launch.py v1.3.0
🖥️
Header UI — Knoppen op Lijn
De header van de native UI is compleet herbouwd. Alle vijf knoppen staan nu perfect op één lijn via pack(side="left"). Stop en Cache vragen bevestiging, Herstart doet stop→wacht→start in eigen thread.
ui/app.py v2.4.0
📊
Live Dashboard Polling
De UI pollt nu elke seconde via after() — volledig thread-safe. Status-indicator, uptime timer, 6 stat-cards en log zijn allemaal live gekoppeld aan het STATS object van de bot.
ui/app.py v2.4.0
🐍
Python Versie Vangnet
FIX_PYTHON.bat verwijdert de oude .venv en maakt een nieuwe aan met de juiste Python versie. updater.py waarschuwt bij Python < 3.10. Nooit meer een kapotte venv na een Python-upgrade.
FIX_PYTHON.bat + updater v1.3.0
🔄
Volledige MANAGED_FILES
De auto-updater miste 6 kritieke bestanden: ui/app.py, ui/setup_wizard.py, key_manager.py, help.py, launch.py en FIX_PYTHON.bat. Allemaal toegevoegd.
updater.py v1.3.0
