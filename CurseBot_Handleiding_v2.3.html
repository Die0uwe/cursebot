02 / EERSTE CONFIGURATIE

API & Tokens instellen

Bij de allereerste start vraagt CurseBot om je tokens. Deze worden versleuteld opgeslagen via Windows Credential Manager.

Setup wizard — verschijnt automatisch bij eerste start
1
Discord Bot Token
Maak een bot aan op discord.com/developers/applications → Bot → Reset Token.
2
CurseForge API Key
Haal je key op via console.curseforge.com → My API Keys.
3
Discord Channel ID
Schakel Developer Mode in → rechtermuisklik op kanaal → ID kopiëren.
4
Opslaan & Starten
Keys worden versleuteld opgeslagen — volgende keer start alles automatisch.
Instellingen — aanpassen na eerste installatie

06 / DIAGNOSTIEK

Foutafhandeling

403 + X-Cache: cloudfront
Tijdelijke Cloudfront WAF IP-blokkade — GEEN auth-fout. Wacht 1–24 uur. Niet herstarten.
403 zonder X-Cache
API key ongeldig of verlopen. Controleer CURSEFORGE_API_KEY in Instellingen → Beveiliging.
0 projecten na start
CF_AUTHOR_SLUG controleren in instellingen. Moet een naam zijn (bijv. dieouwe), geen getal.
Bot stopt na X uur
v2.1.0+ heeft de monitor_loop.error handler. Zorg dat je de nieuwste versie draait.
Geen notificaties
Gebruik /setchannel om een kanaal te koppelen. Controleer bot-rechten via /permissions.
Zoeken geeft 0 resultaten
CF Browser werkt ook zonder bot. Controleer je internetverbinding en CF API key.
